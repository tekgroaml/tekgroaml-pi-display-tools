# 6.2英寸长条屏兼容档

客户条目：**6.2英寸 420×960 长条触摸屏**（已验证输入模式，厂家原生规格待确认）。正式配置档：`6.2inch-420x960-60hz-ltm-zl480`，同名`.sh`便捷入口位于`scripts/profiles/`；正式命名要求2.3.0起的版本。2.2旧名`ltm-420x960-60`继续作为兼容别名。

## 适用依据与边界

已验证触摸样机在420×960、32.4MHz、60Hz下画面完整、闪烁消失。它原始报告420×960、28MHz、约51.85Hz。同尺寸非触摸样机报告同样EDID，测试60Hz后仍亮度闪动，问题未解决。

真实厂家型号未取得，EDID的`LTM ZL480`不代表面板料号。420×960是已成功验证的输入模式，不能直接用来修改商品的原生分辨率标注。360×960试验未通过。

## 客户操作

先让卖家确认SKU/批次，检查屏幕供电和线材，再临时应用。接口编号1/2与`HDMI-A-1/2`一致。此处以接口1举例：

```bash
screen-config --version
screen-config profiles
screen-config list
screen-test stop
screen-config apply --port 1 --profile 6.2inch-420x960-60hz-ltm-zl480 --confirm-profile
```

请提前保存桌面应用文件。该命令可能重启桌面、短暂影响另一块屏幕；保留SSH恢复通道。**没有自动倒计时恢复，不加`--save`不会新增启动设置。**

检查画面完整性、亮度稳定和触摸，成功后才保存：

```bash
screen-test white --screen 1
screen-test pattern --screen 1
screen-test touch --screen 1
screen-test stop
screen-config apply --port 1 --profile 6.2inch-420x960-60hz-ltm-zl480 --confirm-profile --save
```

失败、换屏或需要恢复时：

```bash
screen-config auto --port 1 --save
```

## 匹配与保存

程序核对EDID总长256、各块校验和、厂商/产品标识、名称、详细时序和扩展结构。匹配后只改变第一详细时序的像素时钟及基础校验和，其他描述和扩展块不变。

`--confirm-profile`要求用户核对产品指南，不认证实际物理型号。它不取消EDID匹配。保存项在原配置格式1下增加可选的`profile_confirmed: true`；缺失确认或身份不匹配时启动跳过。4.0英寸720档的旧名`lontium-720`、保存格式及无需确认的调用方式保留。

**完全相同的EDID不能区分触摸/非触摸变体。** 更换实体屏幕时即使名称、序列号相同，也要清除该接口旧设置并重新验证；不能依赖保存身份自动避开同ID的其他产品。

此档不会自动发现或修复触摸映射，也不修改屏幕固件。屏幕自身USB供电不稳仍需独立电源对照；主机没有欠压日志不代表屏幕供电稳定。
