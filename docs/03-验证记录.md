# 验证范围与限制

记录日期：2026-10-25。以下是开发测试的历史记录，不表示下载者的机器已安装、配置或通过同样测试。

## 平台

- Raspberry Pi 4 Model B，Raspberry Pi OS / Debian 12 Bookworm，64位。
- 测试内核`6.12.25+rpt-rpi-v8`，桌面labwc / Wayland。
- 视频模式覆盖480×480@60与800×800@60；已知720×720控制器的时序修正来自此前成功运行的样机测试。
- 同名双USB触摸控制器场景使用可选USB路径中转，已获得两块实体屏幕各自在本屏响应且位置正常的反馈。

不发布样机的账号、主机名、网络地址、完整EDID序列号、实际USB路径或已生成的本机配置。下载后需要自行检测设备并建立配对。

## 已完成的功能检查

- 分别设置HDMI0和HDMI1的可用模式，保存并恢复；改变屏幕身份时跳过不匹配的保存项。
- `auto`重新探测与首选模式恢复；未知显示模式或不匹配的720兼容档被拒绝。
- 双屏全屏黑/白画面的逐像素截图校验，单屏红色控制，颜色循环及单屏退出。
- 网格、内切圆、方向标记与中心十字测试图的截图检查。
- 触摸靶点、轨迹、原生触摸和鼠标模拟输入处理；同名双控制器的运行中配对验证。
- 基础安装、重复安装、systemd单元检查、手动调用配置恢复服务。
- `tap-cycle`具备黑→白→红顺序、手势去重和独立屏幕状态逻辑测试；曾在一块480×480实体输出上完成初始纯黑截图校验。

`tap-cycle`的实物手指切色及双屏同时操作没有取得最终确认，不将软件逻辑测试写成实体输入验收已通过。

## 尚需针对目标系统验证

- 断电冷启动、重新登录、睡眠唤醒和长期运行。
- 多指并发、跨屏同时多指、反复热拔插后的完整恢复。
- 当前分发程序在重新接回720物理屏幕后完整安装、重启和卸载。
- Pi 5、其他系统版本、X11、无桌面系统、多用户图形会话及镜像布局。
- 新分发包在干净系统中的完整安装与卸载验收。

普通模式设置仅接受已报告模式。原始DDC读取当前支持基础EDID与一个扩展块；更多扩展块会报错。三块以上屏幕不在当前程序范围。

## 结果解释

截图证明主机输出缓冲区的颜色和覆盖范围，不证明实际亮度、色准、漏光或所有物理可视边缘。五点触摸命中不等于全屏精密校准或所有多点能力均已验证。

程序的EDID覆盖发生在主机Linux驱动中；触摸中转发生在主机输入层。两者均不写显示器或触摸控制器固件。

## 2.0统一编号回归验证

配置`--port`和测试`--screen`统一为Linux接口编号1、2；板子物理标号仍为HDMI0、HDMI1。新增三个回归测试组，覆盖只读模式查询、set/auto/apply的目标端口与保存键、sudo重新执行时的原始参数，以及非法0/3编号拒绝。合计28项逻辑测试通过；内部配置和原有触摸映射格式不变。此修改未重新部署到实体树莓派，实机更新后需按安装说明使用新参数。

## 2.1版本管理验证

新增版本数值比较、旧安装识别、同版本跳过/修复、主版本确认、降级拒绝、配置格式阻断、内容指纹、暂存期间变更检测、回退恢复及失败注入测试。临时目录测试覆盖了2.0旧安装到2.1的完整文件/命令入口替换，安装凭据写入，以及服务校验失败后的旧应用/配置恢复。平台服务和依赖操作在这些测试中模拟；不把它们当作所有实机、所有断电情况已通过。应用版本2.1.0，命令接口2，配置格式均为1。

版本管理相关测试总计47项通过。实机验证准备时设备掉线，目标包上传未成功，新安装器尚未在样机执行；真实升级、可选触摸服务短暂停止后恢复仍需设备在线验证。此限制不会被模拟测试结果替代。
