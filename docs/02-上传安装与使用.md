# 下载、上传与安装

程序安装到树莓派系统卡中，不需要重新烧录系统，也不改写屏幕固件。GitHub仓库为[tekgroaml-pi-display-tools](https://github.com/tekgroaml/tekgroaml-pi-display-tools)；命令、Python包和安装目录继续使用`pi-setting`，二者不要求同名。

## 1. 平台与前提

- Raspberry Pi 4 Model B，Raspberry Pi OS Bookworm Desktop 64位，labwc / Wayland桌面。
- 要测试的HDMI屏幕已连接并按产品标注供电；触摸需要USB数据连接。
- 树莓派图形桌面已登录，可以在实体终端或从其他电脑通过SSH执行命令。
- 首次安装需要联网下载系统软件依赖。

如果系统里存在本项目早期的`pi-hdmi-720-compat.service`且脚本结构符合受支持格式，安装会备份并停用它，迁移符合条件的720屏设置。没有旧服务时直接跳过；其他来源的服务不自动接管。

## 2. 获取代码

代码仓库：[tekgroaml/tekgroaml-pi-display-tools](https://github.com/tekgroaml/tekgroaml-pi-display-tools)。下面的HTTPS下载方式不要求客户配置GitHub SSH密钥。

### 直接在树莓派下载

在树莓派终端中执行：

```bash
git clone https://github.com/tekgroaml/tekgroaml-pi-display-tools.git pi-setting
cd pi-setting
```

如果没有git，先用系统包管理器安装，或在GitHub页面下载ZIP，解压为`pi-setting`文件夹。无需安装Python的第三方pip包来完成基础安装。

### 从电脑复制到树莓派

macOS、Linux或支持OpenSSH的Windows终端均可先取得项目，再上传。先进入自己存放代码的父目录；没有固定的Mac本机路径要求。

```bash
git clone https://github.com/tekgroaml/tekgroaml-pi-display-tools.git pi-setting
scp -r pi-setting YOUR_PI_USER@YOUR_PI_HOST:~/
ssh YOUR_PI_USER@YOUR_PI_HOST
```

把`YOUR_PI_USER`改成自己的树莓派账号，`YOUR_PI_HOST`改成其IP或主机名。密码在SSH提示时输入，不写入命令文档或代码。

下载ZIP的用户可自行将解压目录改名为`pi-setting`，然后在它的父目录运行同样的`scp`命令。不要把GitHub默认解压文件夹名误认为程序要求的固定目录。

## 3. 安装

在树莓派中，进入刚获取的项目目录。通过上面的上传步骤获取时：

```bash
cd ~/pi-setting
sudo bash scripts/install.sh
```

安装依赖、复制程序到`/opt/pi-setting`，并创建`screen-config`与`screen-test`命令，以及保存配置恢复服务。安装不重启桌面。升级时会短暂停止已运行的测试及触摸中转，完成后恢复原有模式；测试计数和起始颜色重新开始。首次安装不会主动打开测试。安装会比较版本，同版本默认跳过；修复重装需要`--reinstall`。

仅当所需系统依赖都已安装时使用：

```bash
sudo bash scripts/install.sh --no-deps
```

安装输出会给出本机生成的备份目录。首次部署后，建议保存应用数据并验证重新登录、重启及冷启动恢复；当前项目没有宣称所有平台都经过这些验证。

## 4. 检查与操作

以已登录图形桌面的普通用户执行，不要用`sudo screen-test`：

```bash
pi-setting version
screen-config list
screen-config modes --port 2
screen-test pattern
screen-test touch
screen-test tap-cycle
screen-test cycle --interval 5
screen-test stop
```

配置与测试统一编号1、2，与`HDMI-A-1/2`一致；板子印刷的HDMI0/1仅用于找到插口。分辨率示例只适用于屏幕实际支持的模式：

```bash
screen-config set --port 1 --mode 480x480@60 --save
screen-config set --port 2 --mode 800x800@60 --save
```

更换屏幕后重新识别：

```bash
screen-test stop
screen-config auto --port 2 --save
screen-config list
```

只有屏幕识别信息符合验证过的720配置档时，才可使用：

```bash
screen-config apply --port 2 --profile 4.0inch-720x720-60hz-wks-lontium-semi --save
```

6.2英寸触摸样机新增`6.2inch-420x960-60hz-ltm-zl480`档，但非触摸样机同参未修复，且EDID无法区分变体。必须先按[该产品说明](06-6.2英寸长条屏.md)确认适用范围，再使用`--confirm-profile`；先临时测试，实体稳定后再保存，不能仅凭同名驱动板自动套用。

完整命令见[命令说明](01-命令说明.md)，同名双屏的可选输入映射见[触摸配置](04-触摸测试与双屏映射.md)。基础安装不会猜测USB触摸线与HDMI的配对关系。

## 5. 文件位置与日志

这些是程序在Linux中使用的标准位置，不是开发者的个人路径，安装时应保留：

| 位置 | 用途 |
| --- | --- |
| `/opt/pi-setting` | 安装后的代码和文档 |
| `/usr/local/bin/pi-setting`、`/usr/local/bin/screen-config`、`/usr/local/bin/screen-test` | 命令入口 |
| `/etc/pi-setting/config.json` | 用户自行保存的显示设置 |
| `/etc/pi-setting/touch-map.json` | 可选双屏触摸映射，由本机确认后生成 |
| `/var/lib/pi-setting` | 备份、迁移记录、覆盖来源 |
| `/var/lib/pi-setting/installation.json` | 应用版本、内容指纹、安装时间和备份位置 |
| `$XDG_RUNTIME_DIR/pi-setting-test/worker.log` | 当前桌面用户的测试进程日志 |
| `/etc/xdg/autostart/pi-setting-restore.desktop` | 桌面登录后的模式恢复入口 |

```bash
journalctl -b -u pi-setting-boot.service --no-pager
screen-test status
```

如果退出了图形桌面，SSH仍能使用，但测试窗口无法显示。请重新登录桌面。仅在LightDM且已启用桌面自动登录的相应环境中，可以在保存图形应用数据后执行`sudo systemctl restart lightdm`；这会关闭图形应用，不能无条件套用到其他桌面。

## 6. 更新与卸载

先取得可信目标版本。Git克隆目录可用以下方式下载代码；正式发布优先使用已发布的版本标签：

```bash
cd ~/pi-setting
git pull --ff-only
pi-setting check-update --source "$PWD"
sudo pi-setting upgrade --source "$PWD"
```

更新到2.0时请同步更新旧脚本中的配置参数：原`--port 0`改为`--port 1`，原`--port 1`改为`--port 2`；`--screen 1/2`保持不变。已保存JSON配置不改号，详见[变更记录](../CHANGELOG.md)。

旧2.0及更早安装没有`pi-setting`管理命令，第一次用新包中的`sudo bash scripts/install.sh`升级。1.x升到2.x需要`--allow-major`。同版本默认跳过；卸载后重新启用同版本请使用`--reinstall`。详细判断和回退边界见[版本与升级](05-版本与升级.md)。

如果目录存在自己修改的代码，请先保留这些修改，不要强制覆盖。ZIP用户应重新下载到新目录，按照安装步骤更新。

卸载：

```bash
screen-test stop
cd ~/pi-setting
sudo bash scripts/uninstall.sh
sudo reboot
```

卸载保留代码、配置及备份；停止已安装的可选触摸服务并移除其虚拟设备映射。如果曾接管受支持的旧720服务，则恢复其原有启用状态。重启清除运行时EDID覆盖。

## 7. 代码结构与开发验证

```text
bin/                命令入口
src/pi_setting/     显示、EDID、触摸测试、输入中转等模块
scripts/            安装、卸载和可选触摸配置
systemd/            启动服务
desktop/            桌面自动启动入口
tests/              不依赖实机的逻辑测试
docs/               命令、安装和验证范围
```

在任意电脑的项目根目录执行：

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 -m unittest discover -s tests -v
```

该命令不证明真实面板、冷启动或输入设备已经通过实测。已验证范围与未完成项目见[验证记录](03-验证记录.md)。
